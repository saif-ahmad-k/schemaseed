SchemaSeed

Paste a CREATE TABLE in the browser and download JSON, CSV, or SQL inserts. Foreign keys come from the parent rows. The schema never leaves the machine.

  1. Paste a CREATE TABLE. The Shop sample is customers, products, and orders.
  2. Generate a preview. A name becomes a person name, an email becomes an email, and a foreign key uses an id from the parent rows.
  3. Download JSON, CSV, or SQL. No account. The schema and the rows stay in this browser.

Generate data from a schema or from DDL. SchemaSeed is a random SQL data generator for the tables you paste.
