Fake data in other languages

The language control changes the words in the rows: personal names, cities, companies, and sentences. It does not translate your column names or the values locked by a CHECK list. If status must be draft or active, those spellings stay.

Languages

English, Spanish, French, German, Portuguese, Chinese, Russian, Japanese, and Arabic. Email addresses stay in ASCII so they remain usable in a database. A Chinese name that cannot become a URL slug falls back to a row id.

Pick the language before you generate. The same schema can be exported again in another language, and the SQL dialect stays a separate choice.
