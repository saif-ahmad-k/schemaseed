SchemaSeed Guides

Fake data without uploading the schema

A real schema often names customers, internal tables, and relationships you would rather not paste into a chat. SchemaSeed reads that schema in the browser. Parsing and row generation run on your machine. The file you download is the only copy that leaves the tab.

What stays local

  • The CREATE TABLE text, or the CSV header, stays in the page.
  • The generated rows stay in the page until you download JSON, CSV, or SQL.
  • Closing the tab drops the rows. There is no account.

Every table is included, up to 10,000 rows. Foreign keys are filled from the parent rows that were just generated.
