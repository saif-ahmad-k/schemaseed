Generate data from DDL

Generate data from DDL by pasting the CREATE TABLE statements in the script. SchemaSeed reads each table’s columns, types, nullability, CHECK lists, and foreign keys, then builds test rows that fit those definitions.

The tool reads table definitions. It does not run the script, create indexes, or apply a later ALTER TABLE. If a column was added in an alter statement, include it in the CREATE TABLE you paste.

CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  email VARCHAR(255) NOT NULL
);

CREATE TABLE orders (
  id INTEGER PRIMARY KEY,
  user_id INTEGER NOT NULL REFERENCES users(id),
  total DECIMAL(10, 2)
);

The SQL download inserts users before orders, and each user_id is one of the generated user ids. You can also download JSON or CSV for the table you are viewing.
