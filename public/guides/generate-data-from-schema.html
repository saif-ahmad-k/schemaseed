Generate data from a schema

Generate data from a schema you already have, instead of inventing columns by hand. Paste the CREATE TABLE statements. SchemaSeed reads the table names, column names, SQL types, CHECK lists, and foreign keys, then fills the rows.

Download JSON, CSV, or SQL INSERT statements. Parent tables are written first, and each child foreign key is taken from those parent rows. The schema stays in the browser.

What you paste

  • One table, or several tables that reference each other.
  • A CSV header when you do not have SQL yet. Names such as email, city, and created_at choose the generator.

Every table is included, up to 10,000 rows. There is no account.
