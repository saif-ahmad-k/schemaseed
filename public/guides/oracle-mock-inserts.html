SchemaSeed Guides

Oracle mock INSERT statements

Oracle rejects a plain multi-database INSERT file. SchemaSeed writes INSERT ALL, quotes identifiers with double quotes, prefixes strings with N, and formats dates with TO_DATE.

INSERT ALL
  INTO "users" ("id", "email", "created_at") VALUES (1, N'ada@example.com', TO_DATE('2026-10-14 12:00:00', 'YYYY-MM-DD HH24:MI:SS'))
SELECT 1 FROM dual;

Booleans are written as 1 and 0. When several tables are generated, parent tables come first so a foreign key points at a row that exists.

Paste the CREATE TABLE statements, choose Oracle, and download schemaseed.sql.
