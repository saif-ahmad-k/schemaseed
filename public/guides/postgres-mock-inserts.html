PostgreSQL mock INSERT statements

PostgreSQL is the default database in SchemaSeed. The generated SQL is ordinary INSERT syntax you can run in psql, a migration, or a seed script.

INSERT INTO "users" ("id", "email", "active")
VALUES (1, 'ada@example.com', true);

Identifiers are wrapped in double quotes, so a column named order or user still parses. Booleans are true and false. Timestamps use an ISO-8601 value. If orders.user_id references users.id, the users insert is written first.

CockroachDB, YugabyteDB, and the other PostgreSQL-compatible engines use this same export.
