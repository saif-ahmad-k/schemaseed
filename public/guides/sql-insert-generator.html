SchemaSeed Guides

Generate SQL INSERT statements from a schema

JSON is easy to share. A database still wants INSERT syntax that matches the engine. SchemaSeed keeps the same rows and changes the SQL around them.

What actually changes

  • PostgreSQL and SQLite quote identifiers with double quotes and write booleans as true and false.
  • MySQL and MariaDB use backticks and write booleans as 1 and 0.
  • SQL Server uses brackets, 1 and 0, and an N prefix on ordinary strings.
  • Oracle uses INSERT ALL, TO_DATE for timestamps, and SELECT 1 FROM dual.
  • ClickHouse uses backticks and writes datetimes with a space instead of a T.

When several tables are generated, parent tables are inserted first so foreign keys point at rows that exist. JSON and CSV export the table you are viewing. SQL export writes every generated table.
