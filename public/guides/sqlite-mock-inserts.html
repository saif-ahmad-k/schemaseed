SQLite mock INSERT statements

SQLite is the practical choice when the database is a file on disk: a prototype, a desktop app, or a test fixture. SchemaSeed’s SQLite export stays close to PostgreSQL.

INSERT INTO "tasks" ("id", "title", "done")
VALUES (1, 'Write the seed', true);

Identifiers use double quotes. Booleans are true and false, which SQLite stores as 1 and 0. Download the .sql file and run it with sqlite3 app.db < schemaseed.sql after the CREATE TABLE statements already exist.
