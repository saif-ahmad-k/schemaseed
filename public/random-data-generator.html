SchemaSeed Guides

Random data generator

SchemaSeed builds random test rows from a schema you already have. Paste a CREATE TABLE statement, or a line of CSV column names, and download JSON, CSV, or SQL INSERT statements.

What you get

  • Names, emails, cities, prices, dates, and sentences that follow the column name.
  • CHECK lists respected, so a status column only uses the values you wrote.
  • Foreign keys filled from parent rows, with parents inserted first in the SQL file.
  • PostgreSQL, MySQL, SQLite, and SQL Server on the free tier. Oracle, ClickHouse, Snowflake, and BigQuery on Pro.

How a row is chosen

email becomes an email. created_at TIMESTAMP becomes a timestamp. price DECIMAL becomes a money amount. You can override any column before generating. The free limit is the first table and 50 rows. Pro goes to 10,000 rows and keeps every table.

Nothing is uploaded. Close the tab and the rows are gone, unless you downloaded them.
