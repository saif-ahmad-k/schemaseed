Random SQL data generator

A random SQL data generator is useful when the rows still have to match a real schema. SchemaSeed reads your CREATE TABLE DDL and writes INSERT statements for the database you pick: PostgreSQL, MySQL, SQLite, SQL Server, and, on Pro, Oracle, ClickHouse, and others.

What the SQL file contains

  • Random but typed values: emails, names, prices, dates, and the words in a CHECK list.
  • Foreign keys copied from parent rows, with those parents inserted first.
  • Quoting and booleans that match the dialect, so the file can be run after your tables exist.

JSON and CSV are available for the table on screen. The SQL download is one file, schemaseed.sql, and it includes every table, up to 10,000 rows. There is no account.

Generation runs in the browser. The DDL is not uploaded.
