SchemaSeed Guides

Test data generator

Test data fails when orders.user_id points at a user who was never inserted. SchemaSeed generates the parent table first and only uses those ids in the child table. The SQL file is in the same order, so a foreign key constraint can succeed.

What a QA seed usually needs

  • Enough rows to scroll a UI. Free is 50. Pro is up to 10,000.
  • Every table in a multi-table schema, not only the first one. That is Pro.
  • A dialect the database will actually run: PostgreSQL, MySQL, MariaDB, SQLite, SQL Server, Oracle, or ClickHouse.
  • A few bad values. Chaos rewrites about 5% of cells with blanks, nulls where the column allows them, and boundary numbers. Primary keys stay valid.

JSON and CSV export the table you are looking at. SQL export writes every generated table into one file named schemaseed.sql.
